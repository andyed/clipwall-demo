# wunderkammer demo

**Open the demo: https://andyed.github.io/clipwall-demo/**

A pan/zoom wall of 297 Psychodeli Atlas frames. Approach a group without changing the collection, lift an image into the reader, then close and return to your place. The separate filter control changes membership. In 3D, open a stack to spread its contents and return to the original view. Search and zoom-out retain the surrounding collection as context.

Static build for GitHub Pages generated by `scripts/build-demo.mjs` in the wunderkammer repo; images are low-resolution derivatives. Piles last for the visit and links carry the full view; saving either needs the wunderkammer server. This is an experimental demo; dense transitions and cold atlas-loading performance remain work in progress.
