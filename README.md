# clipwall demo

**Open the demo: https://andyed.github.io/clipwall-demo/**

A pan/zoom wall of 297 Psychodeli Atlas frames. Filter, then zoom out: the rest of the collection rises behind on a tilted context plane. Search makes the place you searched from the context and lights up matches. Zoom in until a group heading is cropped and a pinned row title names the group and steps through the collection. Click a group heading to narrow to it.

Static build for GitHub Pages generated by `scripts/build-demo.mjs` in the clipwall repo; images are low-resolution derivatives. Saved piles and compact links need the server and are disabled here.
